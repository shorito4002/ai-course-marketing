## Размышления

**Что не было ясно и как разрешалось:**

- Первое сообщение (карточка оценки) относится не к пользователю по email
  (`burovcevaveronika1@gmail.com`), а показывает имя «Никита Морозов» — но
  git `user.name`, уже настроенный на машине глобально (`shorito4002`),
  дословно совпадает с тегом репозитория на карточке
  (`shorito4002/ai-course-marketing`). Несовпадение отображаемого имени с
  git-логином — не противоречие: воспринял это как одну и ту же учебную
  работу и продолжил её.
- Перед тем как трогать файлы, проверил `git status` в `TestTask` — **git не
  был инициализирован вообще**, хотя отчёт по ДЗ №1 прямо упоминает «один
  коммит». То есть либо коммит существовал где-то ещё и не попал в эту
  папку, либо предыдущая сессия описала git-действия, которых по факту не
  было. Зафиксировал это как факт, а не подогнал историю задним числом —
  `git init` и первый коммит сделаны сейчас, честно с сегодняшней датой.
- `materials/` (PDF/md занятия) в git не кладу — это раздаточные материалы
  курса, а не продукт работы; исключил через `.gitignore`, чтобы не раздувать
  репозиторий. Решение не было продиктовано пользователем напрямую, это моя
  интерпретация «файлы ДЗ №1 не трогать» — не трогать значит не удалять и не
  редактировать, но не обязывает добавлять в git всё подряд.
- 7-й конкурент не был назван пользователем — по правилам `AGENTS.md`
  агент не может сам расширять список источников без вопроса. Нашёл через
  веб-поиск три кандидата (Card.Club, Exnode, Pipl), проверил каждый на
  «открывается без регистрации» — у Card.Club и Exnode `WebFetch` не
  вернул тарифы (503 у Exnode, пустая страница у Card.Club), у Pipl
  (`pipl.io/bank-cards/`) тарифы открылись сразу и по всем 5 критериям
  нашлись цифры. Предложил Pipl пользователю явно, получил подтверждение,
  только после этого добавил в план.
- Перед созданием репозитория на GitHub проверил `gh` CLI — не установлен
  ни в git-bash, ни в PowerShell. Решил не ставить и не логинить его
  самостоятельно (аутентификация — не моё действие), а попросить
  пользователя создать пустой репозиторий на github.com руками и передать
  ссылку; push сделаю сам после этого с подтверждением.
- Прогнал `grep` на секреты (`api[_-]?key|token|password|secret|sk-...`)
  по всему `TestTask` перед первым коммитом. Нашлось одно совпадение — в
  `materials/reference.md`, но это документация Claude Code про сами
  переменные `ANTHROPIC_API_KEY`/`GITHUB_TOKEN` (примеры кода), не реальный
  ключ. Файл всё равно не попал в git (см. выше про `materials/`).
