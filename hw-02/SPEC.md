3. Свести обновлённые факты в `hw-02/facts.md` и обновлённый сравнительный

# Обязательные пункты ДЗ №2 — как выполняем

## 1. Рабочий результат

Обновлённый `hw-02/brief.md` (7 конкурентов вместо 6) + PDF-версия
(`hw-02/mirocard-vs-konkurenty-2.pdf`). Профиль — «Аналитика, продакт,
маркетинг»: результат = оформленный документ.

## 2. Агенты параллельно

7 независимых субагентов в одной сессии — по одному на каждого конкурента
(6 перепроверок + Pipl). Каждый получает: свой сервис, список URL для
проверки, требование цитировать дословно и не выдумывать цифры. Разбор
результатов и сведение в таблицу — в главной сессии (не автоматически, чтобы
не терять контроль над источниками).

## 3. Workflow (обязательно)

`hw-02/workflow/monitor-competitor-tariffs.md` — повторяемая процедура
«мониторинг тарифов конкурентов»: открыть источники из `facts.md` → сверить
с зафиксированными значениями → пометить расхождения (дата, было/стало) →
обновить `facts.md` новой строкой, не удаляя старую → выдать отдельный
отчёт об изменениях. Рассчитан на использование командой Mirocard на
регулярной основе (раз в месяц/квартал), а не разово.
