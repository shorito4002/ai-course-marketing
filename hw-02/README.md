# Mirocard vs конкуренты — ДЗ №2

Продолжение проекта из [ДЗ №1](../README.md) (та же тема, тот же
репозиторий — история коммитов не прерывается, см. `git log`). Своя тема
выбрана вместо готового варианта из задания: это реальная рабочая задача
маркетинга Mirocard, а не учебный пример.

## Что сделано

1. **Обновление сравнения.** Все 6 конкурентов из ДЗ №1 перепроверены на
   актуальные тарифы (2026-08-29 против 2026-08-17), плюс добавлен 7-й —
   **Pipl**. Найдены и честно зафиксированы (не сглажены) два реальных
   расхождения с прошлой проверкой — Wayment потерял подтверждение
   Visa/Mastercard, комиссия EPN Cards оказалась ступенчатой, а не плоской.
   → [`facts.md`](facts.md), [`brief.md`](brief.md)
2. **Агенты параллельно.** Сбор фактов по 7 источникам выполнен 7
   независимыми субагентами одновременно, в одной сессии (плюс отдельный
   субагент на сам Mirocard — 8 всего). Каждый получил свой источник и
   запрет трогать чужой. → детали и находки субагентов в
   [`sessions/session-1.md`](sessions/session-1.md)
3. **Workflow (обязательный пункт).** Повторяемая процедура «мониторинг
   тарифов конкурентов», оформлена как проектный скилл Claude Code —
   [`.claude/skills/monitor-competitor-tariffs/SKILL.md`](../.claude/skills/monitor-competitor-tariffs/SKILL.md),
   резюме и как её использовать — [`workflow/monitor-competitor-tariffs.md`](workflow/monitor-competitor-tariffs.md).
   Не гипотетическая — по ней же собраны факты этой сессии.
4. **PDF.** [`mirocard-vs-konkurenty-2.pdf`](mirocard-vs-konkurenty-2.pdf) —
   титульная страница, оглавление, таблица сравнения, разделы с
   расхождениями. Собран из `pdf-src/brief.html` через headless Chrome
   (`--print-to-pdf`), проверен визуально в браузере перед коммитом.

## Как это открыть

Код не пишется и не запускается — набор markdown-файлов и один PDF.
Порядок чтения:

1. `mirocard-vs-konkurenty-2.pdf` или `brief.md` — если нужен только
   результат.
2. `facts.md` — источники, дословные цитаты, статусы, если нужно
   проверить конкретную цифру.
3. `SPEC.md` — что и почему делали, план на сессию.
4. `sessions/session-1.md` — журнал: промпты дословно, размышления, что
   нашли субагенты, тупики.
5. `workflow/monitor-competitor-tariffs.md` — повторяемая процедура.

## Что не сделано / упрощено

- **Замер «последовательно vs параллельно» не проводился** (необязательный
  пункт). При 8 независимых целях (7 источников + Mirocard) параллельный
  запуск был содержательно оправдан без отдельного замера — сравнивать
  было не с чем: делать те же 8 проверок последовательно ради одного
  сравнения времени не стали из-за дедлайна в тот же день.
- **Git worktrees, изоляция агента, проверка на недоверенный текст,
  оптимизатор контекста** — необязательные пункты, не делались. Основная
  причина — дедлайн в день начала работы; см. `REPORT.md` для честного
  разбора по каждому пункту.
- **Регистрация на PST.NET и EPN Cards** не выполнялась — тот же запрет
  уровня ассистента, что и в ДЗ №1, не снимается разрешением проекта.
- Полный список гипотез и открытых вопросов — в `facts.md` и `brief.md`,
  разделы «Гипотезы» / «Что осталось за рамками».
