# Workflow: мониторинг тарифов конкурентов (обязательный пункт ДЗ №2)

Полный текст процедуры оформлен как **проектный скилл Claude Code**:
[`.claude/skills/monitor-competitor-tariffs/SKILL.md`](../../.claude/skills/monitor-competitor-tariffs/SKILL.md)
— так его подхватывает агент автоматически по описанию задачи («проверь,
не изменились ли тарифы конкурентов»), без необходимости копировать текст
промпта вручную каждый раз.

Здесь — краткое резюме для тех, кто не открывает `.claude/`:

## Что делает

Повторяемая процедура: открыть источники из свежего `facts.md` → сравнить
текущие цифры с зафиксированными → пометить расхождения («было → стало» или
«не подтвердилось») → обновить факты и сравнение новым файлом, не затирая
историю → выдать отдельный отчёт об изменениях.

## Как запускать

1. Взять самый свежий `facts.md` в репозитории.
2. Разбить проверку по сервисам — один параллельный субагент на сервис
   (`Agent`, `general-purpose`, все агенты одним сообщением).
3. Свести результаты вручную, явно показать «было/стало».
4. Записать новые `facts.md` + `brief.md`, не переписывая прежние.
5. Отдельный отчёт: что изменилось, что нет, что осталось непроверенным.

## Уже применён на реальной задаче

Это не гипотетическая процедура — по ней в этой же сессии (2026-08-29)
перепроверены 6 конкурентов из ДЗ №1 и добавлен 7-й (Pipl). Результат —
`../facts.md` и `../brief.md`. Два реальных расхождения, найденные по
этой процедуре (Wayment — Visa/Mastercard, EPN Cards — структура комиссии),
разобраны в разделе «Что изменилось с 17.08.2026» в `../brief.md`.

## Известные ограничения

- `WebFetch` иногда отдаёт текстовое резюме страницы вместо полной разметки
  — важные блоки (например, тарифная сетка по грейдам у EPN Cards) можно
  пропустить, если не попросить явно «открой конкретную подстраницу, не
  только главную».
- Сайты с защитой Cloudflare (пример — wayment.net) иногда отдают 503 на
  прямой запрос — нужен запасной вариант (браузерный инструмент).
- Процедура не решает конфликты между двумя официальными источниками одного
  вендора «на глаз» — конфликт остаётся зафиксированным, а не усредняется.
