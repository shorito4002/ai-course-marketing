# Спецификация

## Что делаем

Сравниваем Mirocard с конкурентами (Плати по миру, WantToPay, Wayment, PST.NET, EPN Cards, FlexCard) — сервисами виртуальных карт для оплаты зарубежных подписок и сервисов, определяем, чем Mirocard отличается по ключевым критериям.

## Для кого и зачем

Для команды Mirocard (маркетинг/контент) — чтобы точно понимать сильные и слабые стороны конкурентов и опираться на факты при описании преимуществ продукта.

## Сценарии

1. Читатель хочет понять, какие сервисы виртуальных карт с крипто-пополнением есть на рынке и чем отличаются — получает сравнительную таблицу.
2. Читатель сомневается, подходит ли Mirocard под нужную ему валюту/платёжную систему — находит ответ в сравнении.
3. По одному из конкурентов нет публичных данных по какому-то критерию — ячейка помечена «нет данных», а не выдуманным значением.

## Состояния

- Готовая таблица: все 5–7 конкурентов и все критерии заполнены, каждое значение со ссылкой.
- Частичные данные: по критерию нет источника — ячейка «нет данных», а не пропуск и не догадка.
- Конфликт источников: два источника дают разное значение — оба указаны, конфликт отмечен явно.

## Критерии сравнения

1. Валюты пополнения
2. Поддержка Visa/Mastercard
3. Комиссия за выпуск карты
4. Поддержка криптовалют
5. Скорость выпуска карты

## Чего точно не делаем

- Не сравниваем с классическими банковскими картами.
- Не приводим ни одной цифры, цены или срока без ссылки на источник.
- Не оцениваем юридическую легальность каждого сервиса по странам.
- Не делаем готовый SEO-лендинг — только сравнительный материал/бриф.

## Допущения

- Берём только сервисы, ориентированные на международные платежи/подписки и крипто-пополнение — это прямые конкуренты Mirocard, а не весь рынок карт.
- Сравниваем по тарифам, опубликованным на сайтах, а не по индивидуальным предложениям — их нельзя проверить.

## Открытые вопросы

Нет открытых вопросов — критерии сравнения зафиксированы в разделе выше.
